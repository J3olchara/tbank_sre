# Скринкаст домашней работы 04

Заранее запущены minikube, приложение с метриками, PostgreSQL sidecar и Helm-релиз VM.

1. Показать `helm list -n monitoring`, `kubectl get pods,svc,pvc -n monitoring`,
   затем pod'ы приложения (три Go и postgres-0 2/2).
2. Port-forward VM, а также API/metrics одного pod. Проверить OpenMetrics рантайма.
3. Выполнить CRUD с точной проверкой дельт бизнес-счётчиков.
4. Запросить через VictoriaMetrics API `up`, `go_goroutines`, `pg_up` и
   `pg_stat_database_xact_commit`.
5. Показать пять бизнес-counters, сохранённых в TSDB.
6. Scale приложения до 4; показать четыре обнаруженных таргета без изменения конфига.
7. Показать `/targets`, вернуть 3 реплики и проверить готовность/сбор.

Во всех kubectl и Helm-командах явно указывать учебный context tbank-sre-hw02.
Пароли и содержимое Secret на экран не выводить. Запись реального экрана,
без подмены результатов, длина до 7 минут. Скрипт: `scripts/record_hw04.py`.
