# Сценарий скринкаста (ориентир: 3–5 минут)

Образ заранее собран и загружен, кластер запущен. В записи обязательно показывать
команды и фактический результат; не тратить время на скачивание Docker/Kubernetes.

1. Показать `minikube version`, `kubectl --context tbank-sre-hw02 get nodes`:
   одна нода Ready.
2. `kubectl apply` Namespace/ConfigMap, создание Secret из шаблона;
   `kubectl apply -f deploy/k8s/postgres.yaml`, дождаться PostgreSQL.
3. `kubectl apply -f deploy/k8s/migrate.yaml`, дождаться Job Complete.
4. `kubectl apply -f deploy/k8s/app.yaml`, дождаться Deployment Available.
5. `kubectl -n taskboard-lab get pods,deploy,statefulset,svc,pvc,job`:
   PostgreSQL Running, приложение Running, миграции Completed, PVC Bound.
6. `kubectl -n taskboard-lab scale deployment/taskboard --replicas=3`,
   rollout status и `get pods -o wide`: три Ready-реплики на одной ноде.
7. `kubectl -n taskboard-lab port-forward service/taskboard 18080:8080`.
8. В браузере открыть localhost:18080, создать задачу «Проверить minikube»,
   изменить статус с «В работе» на «Готово», обновить страницу (данные сохранены),
   удалить задачу.

Во всех командах добавить `--context tbank-sre-hw02`. Рабочие пароли и содержимое
Secret не показывать. В автоматической записи этапы подписаны в терминале;
звуковая дорожка не обязательна. Итоговый MP4 должен быть не длиннее 7 минут.
